# customer_segmentation_project


# Customer Segmentation using Machine Learning

This Jupyter Notebook implements customer segmentation using clustering techniques, helping businesses better understand and categorize their customers based on purchasing behavior and demographic data.

## 📁 File

* `customer_segment.ipynb` – Main notebook containing the data preprocessing, exploratory data analysis (EDA), and clustering (e.g., KMeans) for customer segmentation.

## 📌 Features

* Load and clean customer data
* Perform exploratory data analysis (EDA) with visualizations
* Apply feature scaling and transformation
* Implement KMeans clustering for segmentation
* Visualize and interpret customer clusters
* Evaluate optimal number of clusters using the Elbow Method

## 🧠 Technologies Used

* Python 3
* Pandas, NumPy – Data manipulation
* Matplotlib, Seaborn – Data visualization
* Scikit-learn – Machine learning and clustering algorithms

## 🚀 How to Run

1. Clone this repository or download the `.ipynb` file.
2. Install dependencies:

   ```bash
   pip install pandas numpy matplotlib seaborn scikit-learn
   ```
3. Run the notebook:

   * Open with Jupyter Notebook or JupyterLab
   * Execute each cell sequentially

## 📊 Results

The output includes:

* Cleaned customer dataset
* Visual analysis of features (e.g., Age, Income, Spending Score)
* Cluster visualizations
* Interpretation of each cluster (e.g., high-income high-spenders, low-income cautious spenders)
